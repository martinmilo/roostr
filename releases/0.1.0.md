# roostr 0.1.0

The first public release. roostr prints a project overview from files in `.roostr/`:
`roostr` for the overview, `roostr show <id>` for one process, `roostr changes` for what
changed since a day, `roostr validate` to check the records, `roostr scan` to update the
entrypoints from the project's own scan script, and `roostr init` to start.
